# Exhaust

## **Setting up Exhaust Smoke**

The Vehicle System also includes another optional component called _Vehicle _ExhaustController_ for controlling exhaust particles. It simply drives 2 parameters _SmokeVelocity_ and _SmokeSize_ from any particle system that is attached to it. There is an included Exhaust particle within the plugin, which is also a good starting point to make your own.
